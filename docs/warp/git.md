# git clone
> git clone URL
opis: Pobranie repozytorium i utworzenie lokalnego katalogu.

# git status
> git status
opis: Sprawdzenie gałęzi oraz plików zmienionych i przygotowanych.

# git add
> git add docs/warp/git.md
opis: Dodanie konkretnego pliku do obszaru staging.

# git push
> git push -u origin feature/git-cheatsheet
opis: Publikacja nowej gałęzi i ustawienie śledzenia.

# git pull
> git pull --ff-only origin main
opis: Pobranie zmian bez tworzenia nieoczekiwanego merge commita.

# git fetch
> git fetch origin
opis: Pobranie informacji o zmianach bez modyfikowania plików roboczych.

# git branch
> git branch
opis: Wyświetlenie lokalnych gałęzi i oznaczenie aktywnej.

# git switch
> git switch -c feature/nazwa
opis: Utworzenie gałęzi roboczej i przełączenie na nią.

# git log
> git log --oneline -5
opis: Skrócony podgląd pięciu ostatnich commitów.
