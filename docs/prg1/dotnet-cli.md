# Zestaw komend PRG1

## dotnet --version

przykład użycia: dotnet --version

funkcja: Sprawdzenie zainstalowanej wersji zestawu .NET SDK

## dotnet --list-sdks

przykład użycia: dotnet --list-sdks

funkcja: Wyświetlenie wszystkich dostępnych wersji SDK

## dotnet new list

przykład użycia: dotnet new list

funkcja: Wyświetlenie dostępnych szablonów projektów

## dotnet new console

przykład użycia: dotnet new console

funkcja: Utworzenie aplikacji konsolowej w bieżącym katalogu

## dotnet new console -n

przykład użycia: dotnet new console -n MyApp

funkcja: Utworzenie aplikacji konsolowej w katalogu MyApp

## dotnet restore

przykład użycia: dotnet restore

funkcja: Pobranie zależności wymaganych przez projekt

## dotnet build

przykład użycia: dotnet build

funkcja: Kompilacja projektu i odczyt komunikatów o błędach

## dotnet run

przykład użycia: dotnet run --project MyApp

funkcja: Zbudowanie i uruchomienie wskazanego projektu

## dotnet clean

przykład użycia: dotnet clean

funkcja: Usunięcie plików wygenerowanych podczas kompilacji
