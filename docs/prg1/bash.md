# Zestaw komend UKOS

## pwd

przykład użycia: pwd

funkcja: Wyświetlanie ścieżki bieżącego katalogu

## ls

przykład użycia: ls -la

funkcja: Listowanie plików, także ukrytych, w formacie szczegółowym

## cd

przykład użycia: cd docs/ukos oraz cd ..

funkcja: Przechodzenie do katalogu i katalogu nadrzędnego

## mkdir

przykład użycia: mkdir -p docs/ukos

funkcja: Tworzenie katalogu wraz z brakującymi katalogami nadrzędnymi

## touch

przykład użycia: touch bash.md

funkcja: Tworzenie pustego pliku lub aktualizacja czasu jego modyfikacji

## cp

przykład użycia: cp bash.md bash-backup.md

funkcja: Kopiowanie pliku; wspomnij o opcji -r dla katalogów

## mv

przykład użycia: mv bash-backup.md archive.md

funkcja: Przenoszenie i zmiana nazwy pliku

## rm

przykład użycia: rm archive.md

funkcja: Usuwanie pliku i ostrzeżenie, że operacja omija kosz

## cat 

przykład użycia: cat bash.md

funkcja: Wyświetlanie zawartości pliku w terminalu

## clear

przykład użycia: clear

funkcja: Czyszczenie widoku terminala bez usuwania historii poleceń
